# Lightgun Flash Removal Codes

I started this project to play lightgun games without a screen flash every time I pulled the trigger. The first codes were written for the SindenPS setup, which lets me use a Sinden Lightgun on an original PlayStation. I kept emulator users in mind too.

The tricky part is that a flash can be tied to how the game registers a shot. For each game, I trace what happens when the trigger is pulled and work out which part of the code can be changed without getting in the way of aiming or firing. A different region or disc revision can mean doing that work again.

## Browse the codes

- [Sony PlayStation](./Sony%20Playstation/) — codes for compatible cheat cartridges and discs, plus `.cht` files for RetroArch.

PlayStation is the first system in the project. I plan to add others over time.
